# OVO Tools — T4R

Настольное приложение для работы с задачами, кейсами Easy Redmine и почтой Gmail.

## Политика конфиденциальности

Приложение работает локально на вашем компьютере. Все данные — задачи,
кейсы, переписка, письма — хранятся на вашем же диске и никуда не передаются,
кроме самих сервисов, к которым вы его подключили: вашего сервера Easy Redmine,
вашего ящика Gmail и выбранного вами поставщика языковой модели.

**Что хранится.** Пароли и токены доступа шифруются средствами операционной
системы и хранятся локально. Они не попадают ни в логи, ни в отчёты об ошибках,
ни в открытый доступ.

**Что не хранится.** Пароли отправляются напрямую сервисам-поставщикам по
защищённым каналам и не проходят через сторонние сервера.

**Аналитика.** Приложение не содержит рекламных и аналитических трекеров и
не передаёт телеметрию разработчику.

**Связь.** Вопросы — в репозитории проекта.
